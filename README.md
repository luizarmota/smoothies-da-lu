# 🍓 Smoothies da Lu

Projeto desenvolvido como parte do meu plano de transição de carreira para a área de tecnologia.  
O site apresenta um cardápio interativo de smoothies, com funcionalidades de cálculo de pedido, animações e efeitos visuais — tudo feito com **HTML**, **CSS** e **JavaScript** 

## Funcionalidades

- Interface responsiva com layout em grid
- Animação `fade-in` no resumo do pedido
- Botão "voltar ao topo" funcional
- Campo para nome do cliente com personalização do pedido
- Simulação de carregamento com `setTimeout`
- Mensagem de alerta se o pedido estiver vazio
- Botão de “Limpar Pedido” para resetar as escolhas


##  Tecnologias Utilizadas

- HTML5
- CSS3 (com media queries e efeitos visuais)
- JavaScript (DOM, eventos, animações, interações)
- Google Fonts
- Cloudinary (para hospedagem de imagens)
- GitHub Pages (para publicação)
